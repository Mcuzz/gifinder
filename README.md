# GIFinder

GIFinder es un explorador de contenido multimedia desarrollado con
Vite y TypeScript.

El proyecto utiliza una colección local de GIFs y permite realizar
búsquedas mediante diferentes propiedades de los objetos.

## Tecnologías

- TypeScript
- Vite
- HTML
- CSS
- Git
- pnpm

## Funcionalidades actuales

- Representación tipada de GIFs.
- Galería generada desde un arreglo local.
- Búsqueda por título.
- Búsqueda por autor.
- Búsqueda por etiquetas.
- Búsqueda por descripción.
- Normalización de texto.
- Manejo del caso sin resultados.
- Restauración de la colección al limpiar la búsqueda.
- Interfaz adaptable a pantallas pequeñas.

## Conceptos de TypeScript utilizados
